Затем вам необходимо установить основные зависимости для запуска проекта в вашей системе:

Подождите, пока наборы данных загрузятся, это может занять некоторое время.

Команда проекта:
"Онлайн-школа 'Skypro'" "Андрей Яковлев"

### Зависимости:
Docker (должен быть установлен и запущен Docker Desktop)
Docker Compose
### Установка:
Клонируйте репозиторий:
https://github.com/frostis47/1122/tree/feature/homework
#### Создайте и заполните файл .env согласно шаблону .env.example
#### Соберите и запустите контейнеры
docker-compose up --build
##### Примените миграции. Откройте новый терминал (или командную строку) и выполните:
docker-compose exec web python manage.py migrate
##### Создайте суперпользователя (опционально):
docker-compose exec web python manage.py createsuperuser
Теперь проект должен быть доступен по адресу http://localhost:8000/


Документацию по работе с api можно изучить по адресу: http://localhost:8000/redoc/


### Для остановки контейнера выполните:

docker-compose down
Эта команда остановит и удалит контейнеры, но не удалит образы.

#### Полезные советы
Для просмотра логов всех сервисов в реальном времени, используйте:

docker-compose logs -f
Вы также можете проверить статус ваших контейнеров с помощью:

 docker-compose ps
